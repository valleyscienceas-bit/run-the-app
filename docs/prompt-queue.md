# Prompt queue

Scratch pad for prompts aimed at different branches. Edit here instead of parking text on the clipboard.

**How to use**

1. Write the prompt under the right section.
2. Checkout that branch (`git checkout …`).
3. Open/continue a Cursor chat on that checkout.
4. `@docs/prompt-queue.md` or paste that section into the chat.
5. Clear or strike through the prompt when done.

Hub folder can only be on one branch at a time. For true parallel work, use git worktrees (see [branch-workflow.md](./branch-workflow.md)).
