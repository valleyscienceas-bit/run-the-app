================================================================================
VALLEY SCIENCE - VISUAL STYLE PROFILE
A copy-paste reference for the website's look & feel and the Valerie mascot.
================================================================================

DESIGN PHILOSOPHY (one line)
Cream canvas -> white pillowy cards with hairline borders, oversized rounded
corners, soft slate-tinted shadows, one pastel accent per element, and
ultra-bold Inter type with wide-tracked uppercase micro-labels - all anchored by
Valerie, the gently-animated pink graduate.


================================================================================
A. COLOR PALETTE
================================================================================

BRAND COLORS (defined in src/index.css @theme)
  cream       #FFFDD0   App background, soft badges
  soft-pink   #FADADD   Primary brand accent, Valerie body, focus rings
  sage-green  #87A96B   Secondary accent, success, "good" scores

NEUTRALS (Tailwind slate scale)
  slate-900   #0F172A   Primary text, dark buttons
  slate-600   #475569   Body copy
  slate-400   #94A3B8   Muted labels / captions
  slate-300   #CBD5E1   Inactive icons
  slate-100   #F1F5F9   Borders, gridlines
  slate-50    #F8FAFC   Input fills, inner panels
  white       #FFFFFF   Card surfaces

MASCOT DETAIL COLORS
  ink         #334155   Valerie outlines, cap, eyes (slate-700)
  blush       #FFB6C1   Cheeks
  gold        #F1C40F   Graduation tassel

FUNCTIONAL ACCENTS (used as soft tints, e.g. bg-blue-50 or icon at /500)
  blue, purple, yellow, orange, red  (Tailwind 50 bg + 500 icon)

CHART SCORE COLORS
  >= 80%   #87A96B  (sage green)
  >= 60%   #FADADD  (soft pink)
  <  60%   #FCA5A5  (soft red)

USAGE RULE
  cream = the canvas. white = surfaces on top of it. soft-pink = active/primary
  highlight. sage-green = success/positive. slate-900 = text + main button.
  Use only ONE accent color per card.


================================================================================
B. TYPOGRAPHY
================================================================================

FONT FAMILY
  "Inter", ui-sans-serif, system-ui, sans-serif
  (loaded weights: 400, 500, 600, 700, 800 via Google Fonts)

TYPE ROLES
  Page title       text-5xl font-black tracking-tight        (slate-900)
  Section heading  text-xl font-black
  Stat value       text-3xl font-black
  Body             text-slate-600 font-medium leading-relaxed
  Micro-label      text-[10px] font-black text-slate-400 uppercase tracking-[0.2em]
  Pill / eyebrow   uppercase tracking-[0.2em]  (up to tracking-[0.3em])

SIGNATURE CHOICE
  font-black (heavy) on nearly all headings/labels/buttons, paired with
  font-medium body text. Heavy + airy.
  NOTE: the font import only loads up to 800. For true 900 weight, add 900 to
  the Google Fonts import in src/index.css.

================================================================================
G. VALERIE - MASCOT SPECIFICATION
================================================================================
A friendly graduate "blob" rendered as inline SVG on a 200x200 viewBox.

CONSTRUCTION & COLORS
  Glow         radial #FADADD 0.4 -> 0   (circle r=80 behind body)
  Body + head  fill #FADADD, stroke #334155 @ strokeWidth 4 (rounded organic path)
  Cheeks       #FFB6C1 @ 0.6 opacity, r=6
  Eyes         #334155, with white shine dots, r=5
  Grad cap     #334155, tassel/bead #F1C40F (gold)
  Arms         stroke #334155 @ strokeWidth 6, round caps
  Legs         #334155 rounded rects (rx=4)

EXPRESSIONS (via `expression` prop)
  happy     gentle smile curve
  excited   open filled smile
  thinking  flat line
  proud

MOTION LANGUAGE (core to her personality)
  idle "breathing"  body path morphs +/-2px, 4s easeInOut, infinite
  head bob          y: [0,-2,0], 4s
  blink             eyes scaleY [1,1,0.1,1,1] every ~3s
  wave              right-arm path animates when isWaving=true
  spin              full 360 rotate when isSpinning=true (2s linear)
  hint bubble       "Need a hint?" fades in once (no bounce)

SIZING IN USE
  48px    sidebar logo
  56-64px headers / avatars
  200px   hero
  Always place her on a light surface (cream/white) so the pink glow reads.
